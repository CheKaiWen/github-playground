# Event-Day Checklist (print me)

## T-2 days
- [ ] Repo created, public, project pushed
- [ ] Settings → Pages → Source = **GitHub Actions**
- [ ] Settings → Actions → fork-PR approval = “first-time contributors new to GitHub”
- [ ] Pages URL works: `https://OWNER.github.io/github-playground/`
- [ ] Full dry run with a second account (see facilitator guide §13)
- [ ] Test profile + test PR + test fork cleaned up
- [ ] Helpers briefed (1 per ~15 people), know the guide

## T-1 hour
- [ ] Phone hotspot ready as Wi-Fi backup
- [ ] Projector: Community Wall page open (`index.html#wall`)
- [ ] QR poster printed / on-screen (`materials/qr.html`), short URL written on the board
- [ ] Logged in to GitHub on the facilitator laptop; `gh auth status` OK
- [ ] Bulk-merge script open in a terminal (facilitator guide §6)
- [ ] Spare chargers, sticky notes (red = need help, green = done)
- [ ] Printed cheat sheets (`materials/git-cheatsheet.html` → Print)

## During
- [ ] Welcome + privacy rule: **nicknames, not personal info**
- [ ] Mission 0 is the longest: circulate. Pair up the stuck with the fast
- [ ] Approve fork workflows if PR checks say “waiting”
- [ ] Merge PRs continuously; announce each merge
- [ ] Reminder: Pages needs 1–3 minutes after merges
- [ ] Point early finishers to Resources → Bonus missions

## After
- [ ] Final bulk merge; wait for green deploy; screenshot the Wall 📸
- [ ] Share the site link
- [ ] Optional reset: remove all but `participants/sample.json`
