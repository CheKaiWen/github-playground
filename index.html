How it works

Six short missions. Every Git command is typed by you in a real terminal. The website only helps you fork and open the pull request.

1

Set up & learn

Install Git, meet the terminal, and understand what Git and GitHub actually are (with pictures).

2

Make a change

Fork the project, clone it, create a branch, add a tiny JSON file about you, then commit and push.

3

Go live

Open a pull request. A facilitator merges it, and your emoji appears on the Community Wall.
